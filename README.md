# eco

## Ecobank WealthAI Studio
Enterprise Wealth Management Platform & AI Inference Center for Ecobank Group RFP Round 2 Demo.

### Features
- **Client 360° & Cadence (Q8)**: Multi-jurisdiction wealth profiles (Ghana, Côte d'Ivoire, Kenya) with event-driven Flexcube CDC simulation.
- **AI Recommendation Engine & XAI (Q9)**: Hybrid deterministic regulatory rules + LightGBM/GradientBoosting propensity with SHAP-style attribution waterfalls.
- **Goal Simulation & Fan Chart (Q10, Q13)**: 60fps canvas Monte Carlo fan chart (500 stochastic iterations) with real inflation-adjusted purchasing power.
- **Robo-Advisory with Regulatory Guardrails (Q11)**: Statutory compliance gates under SEC Ghana Regulation 34 & WAEMU CREPMF guidelines.
- **African Market AI Evidence (Q12)**: Trained on real Sub-Saharan Financial Inclusion Dataset (23,524 records), achieving 0.8789 ROC-AUC.
- **Francophone WAEMU Tax Engine (Q14)**: UEMOA IRVM statutory tax engine and French UI localization.
- **Cryptographic Audit Vault (Q21-Q23)**: Immutable SHA-256 hash-chained audit ledger with sub-200ms regulatory dossier export.

### Quickstart
1. Ensure Python 3.9+ is installed.
2. Run `Launch_AI_Demo.bat` or:
   ```bash
   python server.py
   ```
3. Open `http://localhost:8080/index.html` in your browser.
